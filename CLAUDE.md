# Regras do repositório

## Commits e Pull Requests

- Nunca inclua o nome do Claude (ou qualquer atribuição de IA) nos commits: sem linhas `Co-Authored-By: Claude ...`, sem menções a "Claude" ou "Claude Code" na mensagem.
- O mesmo vale para descrições de Pull Requests: sem rodapé "Generated with Claude Code".
- Sempre que terminar uma alteração, faça commit das mudanças com uma mensagem explicando o que foi feito, com no máximo 20 palavras.
